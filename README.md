# Feed This to Your AI Agent. Avoid the UI Mistakes That Cause Hours of Rework.

### 把这份指南交给 AI Agent，避开那些会造成数小时返工的 UI 设计错误

*Vibe coding moves quickly. UI mistakes compound even faster.*

This publication turns lessons from real UI failures into safeguards that an AI coding agent can apply while designing, implementing, or repairing an interface. It helps prevent patch-on-patch CSS, accidental changes to approved UI, incomplete interaction states, asset confusion, scrolling and positioning failures, and verification that stops at one isolated screen.

这份指南把真实 UI 迭代中反复出现的问题整理成可以直接交给 AI Agent 使用的防错规则，帮助减少视觉修改错误与重复返工，同时不会把项目限制在固定的视觉风格中。

## Use it in one step / 一步使用

Download the language package you need, then attach its `GUIDE.md` once at the start of an AI coding task. Ask the agent to apply the relevant safeguards without limiting visual exploration.

下载所需语言包，在开始 AI 编码任务时附上其中的 `GUIDE.md` 一次，并让 Agent 在不限制视觉探索的前提下应用相关防错规则。
